XZ UTILS - CADENA DE VALOR DE CIBERSEGURIDAD

Contenido:
- index.html: sitio web interactivo.
- styles.css: estilos y diseño adaptable a móvil.
- script.js: interacción de selección de áreas de la cadena de valor.

Cómo abrir:
1. Extrae la carpeta.
2. Abre index.html con Chrome, Edge o Firefox.
3. Haz clic en las áreas de apoyo o en las cinco actividades primarias para ver su explicación y aplicación al caso XZ Utils.

No requiere instalación ni servidor. La tipografía externa requiere conexión a Internet; si no hay conexión se usarán fuentes de respaldo.

Nota académica:
La cadena adapta el modelo de valor de Porter a un ciclo de seguridad de software. Las actividades primarias representan controles de entrada, operación, distribución, comunicación y respuesta. Las actividades de apoyo sostienen ese ciclo.
